Langkah Pasang (30 detik)

  1. Buka folder Download di HP kamu, lalu ketuk file OverlayOps-1.2.0-release.apk.
  2. Kalau muncul peringatan, aktifkan “Izinkan dari sumber ini” / Install unknown apps untuk aplikasi File Manager atau browser kamu. Ini normal untuk APK di luar Play Store.
  3. Selesaikan instalasi, lalu buka AppsPerms di launcher.
  4. Jalankan Shizuku (Wireless Debugging / root), lalu tekan Minta izin di dalam AppsPerms dan pilih “Izinkan selalu”.
  5. Selesai! Kamu sudah bisa mengatur 19 AppOps untuk semua aplikasi secara real-time.
⚠️ Baru pindah dari versi Debug ke Release?
Signature build release berbeda dari debug. Uninstall dulu versi debug/lama, baru pasang versi release, lalu berikan izin Shizuku sekali lagi.
