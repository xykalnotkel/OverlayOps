Sudah pernah pasang versi lama (OverlayOps)?

Mulai v1.3.0 nama paketnya berubah (app.overlayops → app.appsperms), jadi Android menganggapnya aplikasi baru. Uninstall dulu versi lama, baru pasang AppsPerms, lalu berikan izin Shizuku sekali lagi. Konfigurasi lama tidak ikut pindah — pakai Backup konfigurasi di versi lama, lalu Restore di versi baru kalau mau cepat.

Layar Pengaturan

Atur bahasa, urutan daftar bawaan, peringatan UID bersama, dan konfirmasi mode berisiko — semua tersimpan di perangkat, tanpa akun dan tanpa internet.

Peringatan Mode Berisiko

Memilih Diblokir atau Diabaikan untuk app yang memang meminta izin overlay kini ditanya dulu, plus penjelasan konsekuensinya — supaya tidak ada app yang tiba-tiba rusak tanpa kamu sadari.

Deteksi UID Bersama

AppOps disimpan per-UID, jadi app dengan UID sama (klon / profil kerja) berubah bersamaan. AppsPerms sekarang menghitungnya dan memberi tahu sebelum kamu mengubah sesuatu.

Unit Test & Build Terverifikasi

Parser perintah appops (bagian paling rawan) kini punya unit test yang jalan di CI setiap kali kode berubah — termasuk untuk format keluaran ROM yang berbeda-beda.

Kenapa AppsPerms Tidak Ada di Google Play Store?

Biar transparan dari awal: bukan karena aplikasi ini ada virus, malware, atau melanggar keamanan. Alasannya adalah keterbatasan modal untuk biaya pendaftaran akun Google Play Console ($25 USD) dan proses birokrasi verifikasi korporasi Google yang sangat rumit untuk pengembang independen. Selain itu, kebijakan Google Play saat ini sangat membatasi aplikasi pengelola izin sistem/Shizuku. Dengan distribusi langsung via GitHub Releases, AppsPerms tetap 100% gratis, bebas monopoli, tanpa iklan, dan kode sumbernya terbuka untuk diaudit siapapun.

Kemampuan Pengelolaan Izin Lengkap

Kendalikan privasi sistem dan hak akses aplikasi dengan presisi tinggi.

Real-Time 0ms & Anti-Lag

Menggunakan Optimistic UI State dan Partial Payload Diffing. Pergantian izin langsung bereaksi instan tanpa jeda pemrosesan latar belakang.

Kendali Penuh 19 AppOps

Atur Display Over Other Apps, akses Kamera, Mikrofon, Lokasi, Clipboard, Wake Lock, Read SMS, hingga Notifikasi Pop-up pada setiap aplikasi.

Pemisah App Sistem vs User

Daftar otomatis terpisah rapi antara aplikasi pihak ketiga yang diinstall pengguna dan aplikasi bawaan sistem dengan filter tipe yang fleksibel.

Mode Ignore (Bypass Crash)

Mendukung mode cerdas IGNORED: izin diblokir secara senyap tanpa melempar SecurityException, mencegah app bermasalah mengalami force close.

Backup & Restore Clipboard

Ekspor seluruh konfigurasi izin ke format teks sederhana yang dapat disalin ke clipboard dan dipulihkan kembali sewaktu-waktu.

Arsitektur Shell-First

Kompatibel dengan berbagai ROM (HyperOS, One UI, ColorOS, Pixel) dengan fallback otomatis ke perintah resmi appops via Shizuku.

Panduan Cepat via Shizuku

Hanya 3 langkah mudah untuk mulai mengelola izin tanpa root.

Langkah 1

Jalankan Shizuku

Buka Shizuku di HP kamu. Di Android 11+, gunakan opsi Wireless Debugging untuk start tanpa PC. Jika HP sudah root, pilih start via root.

Langkah 2

Pasang AppsPerms

Download file AppsPerms-1.3.0-release.apk di atas, pasang di perangkatmu, lalu buka aplikasinya.

Langkah 3

Setujui Izin Shizuku

Tekan Minta izin pada kartu sambungan, lalu pilih "Izinkan selalu". Kamu langsung bisa mengatur izin seluruh aplikasi secara real-time.
